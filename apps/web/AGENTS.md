# Límites de `apps/web/`

Responsable: `saulfsd98-cloud` (frontend y UI/UX).

- Mantén aquí las secciones de análisis, búsqueda y reportes, los componentes
  visuales y las pruebas unitarias del frontend.
- Atiende accesibilidad y facilidad de uso, incluidas las necesidades de
  personas mayores.
- Consume contratos de `contracts/`; no cambies API, IA, seguridad ni archivos
  compartidos unilateralmente.
- Para un cambio transversal, abre Issue o PR con justificación y solicita
  revisión de los propietarios afectados y `mauriish`.
- Conserva cambios existentes de otros integrantes.
