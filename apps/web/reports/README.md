# Reportes

La ruta `/report` muestra una vista previa del reporte con:

- Tipo de escenario.
- Resultado de la evaluación.
- Origen del análisis.
- Estado pendiente de envío.

Desde esa vista se accede a `/report/formulario`, un asistente de tres pasos:

1. Relato de lo ocurrido, con opción de dictar a texto.
2. Evidencia opcional: captura o texto pegado.
3. Datos de contacto opcionales.

Al finalizar se muestra una confirmación que aclara que es una demostración.
El registro real requiere la API de reportes y todavía no está implementado.
