# Componentes visuales

Componentes compartidos del portal:

- `site-header.tsx`: cabecera con logo y navegación Check, Report y Protect.
- `risk-badge.tsx`: insignia de riesgo con la colorimetría acordada.
- `result-panel.tsx`: panel reutilizable para resultados de análisis.
- `simple-captcha.tsx`: comprobación simulada de un solo botón, accesible y sin
  rompecabezas, con estados pendiente, verificado, error y reintento.
- `ui/`: componentes generados por shadcn/ui.

Mantener accesibilidad, contraste y consistencia visual.
