# Pruebas

Propietaria: @aguillonmarthaguadalupe-lab. Organiza aquí pruebas generales de
integración, seguridad y E2E, independientes y basadas en contratos públicos.
Cada módulo mantiene sus pruebas unitarias junto a su código.

Los equipos pueden proponer casos mediante PR con revisión de la propietaria.
No cambies código de producción para adaptar pruebas ni dependas de detalles
internos de otro módulo.

`evaluation/` contiene el dataset sintético etiquetado de H26-33 y sus
validaciones, basadas en los contratos públicos de `contracts/`.
