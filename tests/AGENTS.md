# Límites de `tests/`

Responsable: `aguillonmarthaguadalupe-lab` (QA y Security).

- Organiza pruebas generales de integración, seguridad y E2E basadas en
  contratos públicos.
- Las pruebas unitarias y su documentación específica pertenecen al módulo
  correspondiente.
- Mantén las pruebas independientes, deterministas y aisladas; no modifiques
  código de producción de otros módulos para adaptarlas.
- Solicita revisión de los propietarios afectados para cambios transversales y
  conserva el trabajo existente.
